# ربط Shopify — دليل الإعداد

الكود جاهز في المستودع (`lib/shopify.ts`، `app/api/shopify/*`، وبطاقة «شوبيفاي» في التكاملات). ما يبقى هو إعداد تطبيق Shopify نفسه ووضع بيانات الاعتماد على الخادم. أسماء الأزرار في لوحة Shopify تتغيّر بين فترة وأخرى، فإن اختلف اسم فابحث عن المعنى.

## 1) إنشاء التطبيق (Shopify Partners)
1. حساب مجاني على https://partners.shopify.com ثم **Apps ← Create app** (إنشاء يدوي).
2. اسم التطبيق: `Linkly`.
3. أنشئ **متجراً تطويرياً** من Partners (Stores ← Add store ← Development store) للتجربة.

## 2) إعدادات التطبيق (Configuration)
| الحقل | القيمة |
|---|---|
| App URL | `https://linklysa.io/api/shopify/connect` |
| Allowed redirection URL(s) | `https://linklysa.io/api/shopify/callback` |
| Embedded app | **مُطفأ** (التطبيق غير مضمَّن في لوحة Shopify) |
| Access scopes | `read_orders` و`read_customers` |
| Webhooks API version | يطابق `SHOPIFY_API_VERSION` (الافتراضي في الكود `2026-10`) |

### Webhooks الإلزامية للخصوصية (Compliance webhooks)
في قسم Webhooks/Privacy ضع الرابط نفسه للثلاثة:

| الحدث | الرابط |
|---|---|
| Customer data request | `https://linklysa.io/api/shopify/webhook` |
| Customer data erasure | `https://linklysa.io/api/shopify/webhook` |
| Shop data erasure | `https://linklysa.io/api/shopify/webhook` |

> أحداث الطلبات والسلات (`orders/create`، `orders/updated`، `checkouts/create`، `checkouts/update`، `app/uninstalled`) **لا تُضبط هنا**: يسجّلها الكود تلقائياً لكل متجر عند الربط. تسجيلها في الإعدادات أيضاً سيُرسل كل حدث مرتين.

## 3) الوصول لبيانات العملاء المحمية (Protected customer data)
القراءة من الطلبات (الاسم والجوال) تحتاج طلب وصول من لوحة Partners ← تطبيقك ← **API access requests ← Protected customer data**. اختر مستوى يشمل الاسم والجوال (Level 2) وأدخل التبرير:

- **الغرض:** إرسال إشعارات حالة الطلب وتذكيرات السلات المتروكة للمتسوّق عبر واتساب، والإجابة عن استفساره عن طلبه، نيابة عن التاجر.
- **الحدّ الأدنى:** نقرأ الاسم والجوال ورقم الطلب وحالته ومبلغه وبيانات الشحن فقط.
- **الحماية:** رموز الوصول مشفّرة، وصول مقيّد بصلاحيات الفريق، ولا بيع ولا استخدام إعلاني، ويُحذف ما نحتفظ به عند ورود طلب خصوصية من Shopify (webhooks أعلاه).
- **سياسة الخصوصية:** https://linklysa.io/privacy

## 4) بيانات الاعتماد على الخادم
من **Client credentials** في التطبيق، أضف في Cloud Run (`linkly` ← Edit & deploy new revision ← Variables & Secrets):

| المتغير | القيمة | ملاحظة |
|---|---|---|
| `SHOPIFY_CLIENT_ID` | Client ID | متغير عادي |
| `SHOPIFY_CLIENT_SECRET` | Client secret | **سرّ** (Secret Manager). هو نفسه يوقّع OAuth والـwebhooks، فلا يوجد سرّ webhook منفصل |
| `SHOPIFY_SCOPES` | اختياري | الافتراضي `read_orders,read_customers`؛ يجب أن يساوي ما في التطبيق |
| `SHOPIFY_API_VERSION` | اختياري | الافتراضي `2026-10`؛ يجب أن يطابق «Webhooks API version» في التطبيق |

## 5) التجربة
1. من لوحة Linkly (حساب المالك): **التكاملات ← شوبيفاي**، أدخل `your-store.myshopify.com`، **ربط المتجر**.
2. وافق على الصلاحيات في شاشة Shopify. يجب أن تعود برسالة «تم ربط متجر شوبيفاي بنجاح».
3. أنشئ طلباً تجريبياً في المتجر التطويري ثم شحنه (Fulfill). المتوقع:
   - حدث إنشاء الطلب ثم إشعار «تم الإنشاء» (إن فُعّل وله قالب معتمد).
   - عند الشحن إشعار «تم الشحن»، وعند التسليم (إن حدّث شركة الشحن الحالة) إشعار «تم التسليم».
   - عند الإلغاء إشعار «ملغي».
4. ابدأ دفع طلب ثم اتركه: تُجدول تذكيرات السلة المتروكة بعد المدة المضبوطة (مع رقم الجوال في الـcheckout).
5. اسأل من واتساب «وين طلبي 1001»: يردّ بحالة الطلب (بعد التحقق من رقم الجوال).

## 6) النشر
- **متجر واحد أو عدة متاجر محددة:** Distribution ← **Custom distribution** ← أنشئ رابط تثبيت لكل متجر (لا مراجعة App Store).
- **قائمة App Store العامة:** تحتاج مراجعة Shopify. قبلها تأكد من: سياسة الخصوصية والدعم، الـwebhooks الإلزامية (أعلاه)، حدّ أدنى للصلاحيات، وأن التسعير يتوافق مع سياسة Shopify للفوترة (راجع قسم Billing في شروط App Store إن كان التطبيق مدفوعاً).

## حدود وملاحظات
- **الطلبات الأقدم من 60 يوماً:** `read_orders` لا يقرأها. استعلام الطلب القديم يتطلب صلاحية `read_all_orders` التي تحتاج موافقة منفصلة.
- **الجوال:** يُقرأ من الطلب أو العميل أو عنوان الشحن/الفوترة؛ إن لم يُدخل المتسوّق جوالاً فلا يُرسل له شيء.
- **السلة المتروكة:** Shopify لا يرسل حدث «سلة متروكة» مباشرة؛ نستخدم `checkouts/*` ونُلغي التذكير تلقائياً عند وصول طلب من الجوال نفسه.
- **متجر واحد ← مساحة عمل واحدة:** يرفض الربط إن كان المتجر مربوطاً بحساب آخر في لنكلي.

## استكشاف الأخطاء
| العَرَض | السبب المحتمل |
|---|---|
| «الربط غير مفعّل بعد على الخادم» | `SHOPIFY_CLIENT_ID/SECRET` غير موجودين في الـrevision الشغّال |
| «تعذر التحقق من توقيع شوبيفاي» | Client Secret خاطئ، أو الـRedirect URL غير مطابق |
| «تم الربط لكن تعذّر تسجيل بعض الأحداث» | نقص الصلاحيات أو إصدار API غير مدعوم؛ راجع `SHOPIFY_API_VERSION` |
| الأحداث تصل بـ401 | السرّ في Cloud Run لا يطابق Client secret الحالي |
| لا تصل رسائل واتساب | القالب غير معتمد، أو الإشعار مُطفأ، أو لا جوال في الطلب |
