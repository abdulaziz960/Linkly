# قاموس مصطلحات الواجهة

مصطلح واحد لكل معنى، في كل صفحة. إن احتجت مصطلحاً جديداً فأضفه هنا أولاً.

| المعنى | في الواجهة العربية | In English UI | ملاحظة |
|---|---|---|---|
| شخص يعمل في حساب الشركة | الموظف | Employee | لا نستخدم «عضو» أو «مستخدم» لهذا المعنى |
| مجموعة موظفين | الفريق | Team | «أعضاء الفريق» مقبولة فقط عند الكلام عن الانضمام لفريق |
| من يراسل الشركة ويشتري منها | العميل | Customer | لا نستخدم «زبون» |
| عميل لم يشترِ بعد | العميل المحتمل | Lead | «ليد» مستخدمة في بعض النصوص القديمة وتُستبدل تدريجياً بـ«عميل محتمل» |
| الشركة صاحبة الحساب | مساحة العمل / حساب العميل | Workspace | «حساب العميل» في القائمة الجانبية فقط |
| خطة الاشتراك | الباقة | Plan | |
| اشتراك الشركة في Linkly | الاشتراك | Subscription | |
| رصيد رسائل الحملات | رصيد الحملات (بالرسائل) | Campaign balance (messages) | |
| قالب واتساب المعتمد من Meta | القالب | Template | |

## الأرقام والتواريخ والأسهم

- الأرقام غربية (1,234) في العربية والإنجليزية: `formatNumber` و`formatPercent` و`formatSar` من `lib/format.ts`.
- التواريخ ميلادية بتوقيت الرياض وساعة 24: `formatDateTime` و`formatFullDateTime` و`formatRelativeTime` من `lib/time.ts`. لا تستدعِ `toLocaleString` بلغة محلية داخل المكوّنات.
- الأسهم تتبع الاتجاه: `t("←", "→")` للتقدّم، ولا نكتب سهماً ثابتاً في نص يظهر باللغتين.
